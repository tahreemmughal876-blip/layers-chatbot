## 🍰 About

**Layers Bakery** is a customer-support chatbot built for a fictional bakery. Customers can
ask about cakes, flavors, sizes, and prices, and get answers grounded strictly in the
bakery's own menu data — no invented items, no invented prices.

The whole UI is themed around a real bakery counter: a warm cream-and-espresso palette,
a scalloped "awning" header, and chat bubbles styled like little order tickets.

---

## ✨ Features

- 🤖 **Dual AI providers** — answers can come from **Gemini** or **OpenAI**, switchable
  live from a toggle in the UI, no reload required
- 📋 **Menu-driven prompts** — the system prompt is generated automatically from
  `cakes.json`, so updating prices or flavors never means touching prompt text by hand
- 💬 **Conversation memory** — short-term chat history is passed along so follow-up
  questions ("what about the 6 inch?") stay in context
- ⚡ **Quick-prompt chips** — one-tap common questions for a faster first interaction
- 🎨 **Custom bakery theme** — Tailwind-only styling, ticket-style bubbles, scalloped
  awning header, warm color palette
- 🔒 **Environment-based keys** — API keys are kept out of source and loaded from
  `.env.local`
